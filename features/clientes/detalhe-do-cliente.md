# Detalhe do cliente

Reúne dados e operações do cliente nas áreas de negócio contratadas pela empresa.

## Dados e ações

| Recurso ou ação | Conteúdo | Plano |
| --- | --- | --- |
| Dados | Nome, telefone, e-mail, CPF ou CNPJ, endereço e observações. | Todos os planos |
| Nova venda | Iniciar uma venda para o cliente. | Vendas e Vendas Pro |
| Nova ordem de serviço | Iniciar uma ordem para o cliente. | Serviços e Serviços Pro |
| Novo aluguel | Iniciar um aluguel para o cliente. | Aluguéis e Aluguéis Pro |

As ações e informações respeitam as áreas disponíveis e as permissões de acesso, incluindo acesso separado ao Financeiro.

## Histórico comercial

| Consulta | Plano |
| --- | --- |
| Visão geral | Todos os planos |
| Vendas | Vendas e Vendas Pro |
| Serviços | Serviços e Serviços Pro |
| Aluguéis | Aluguéis e Aluguéis Pro |
| Financeiro | Vendas Pro, Serviços Pro ou Aluguéis Pro, na respectiva área; exige permissão própria |

Alterar ou arquivar o cliente não reescreve os dados preservados nos pedidos anteriores.

## Recursos Pro

Em Vendas Pro, Serviços Pro ou Aluguéis Pro, sempre limitadas à respectiva área. O resumo e as atividades avançadas incluem apenas as áreas com Pro; os dados básicos do cliente continuam compartilhados.

| Recurso | Descrição |
| --- | --- |
| Cadastro | Tags e data de início do relacionamento. |
| Resumo | Total gasto, vendas, serviços, aluguéis e saldo pendente. |
| Histórico | Atividades e arquivos vinculados ao cliente. |
